## 📐 Signal Format

```
⭐⭐ 05:53 SELL  rate=88%  move=$8.72  max=$19.31  med=$7.70  win=60min  samples=17
```

- **05:53**: Entry time in UTC+1 (Algeria) — minute-precision
- **SELL**: Direction
- **rate=88%**: in 88% of 17 same-weekday days, price moved DOWN in next 60 minutes
- **move=$8.72**: average dollar movement in DOWN direction
- **max=$19.31**: largest historical DOWN movement
- **med=$7.70**: median (typical) DOWN movement
- **win=60min**: optimal window size = 60 minutes
- **samples=17**: based on 17 same-weekday days (1m data)
