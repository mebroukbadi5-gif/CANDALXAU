## 📈 Accuracy Calculation

Multi-factor model combining directional bias, time of day, weekday, and movement probability:

```
accuracy = (max(up_pct, down_pct) × 1.45)         # Boosted directional bias
         + hour_bonus                            # Peak hours 12-16 UTC = +9 to +13
         + day_bonus                             # Tue/Thu = +6, Wed/Fri = +5
         + expiry_bonus                          # M1=+18, M3=+15, M5=+12, M10=+8
         - minute_penalty                        # 00=0, 15=-1, 30=-2, 45=-3
         - target_penalty                        # $1=0, $2=-2, $3=-4, $5=-6
         + movement_bonus                         # avg_move ≥ 2× target = +6
```

Capped at 98% (no signal is ever 100% guaranteed).
