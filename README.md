## 📈 How Accuracy Is Calculated

```
For each (weekday, hour):
  - Take 12 candles of 5 minutes (= 1 hour) over 974 days
  - entry_price = close[candle H]
  - max_high = max(high[candles 1-12])
  - min_low  = min(low[candles 1-12])
  - max_up   = max_high - entry_price
  - max_down = entry_price - min_low

  if max_up >= max_down: dominant_dir = UP
  else:                  dominant_dir = DOWN

  up_pct   = (days with UP dominant) / 974 × 100
  down_pct = (days with DOWN dominant) / 974 × 100

  accuracy = max(up_pct, down_pct)
```
